# 叠澜 · Tidemeld

叠澜（Tidemeld，原名 maxbo）是一个开源、非商业的社交媒体聚合客户端。支持微博，已加入 X（x.com）网页接入原型、多账号管理和本地聚合信息流；iOS 已验证单个真实 X 账号登录与信息流读取。Android 版使用 Kotlin 和 Jetpack Compose，iOS 版使用 SwiftUI。

> **状态：早期测试版。Android 版在 Releases 发布；iOS 版还没有发布，只能从源码构建。** 方案与进度见 [docs/PLAN.md](docs/PLAN.md)。

## 功能

- **账号管理**：添加账号时选择微博或 X，使用对应平台的官方网页登录；支持同平台多个账号和跨平台同时登录。凭据分别保存在本机，移除单个账号不会退出其他账号。旧版微博登录态自动迁入账号列表。
- **首页**：未登录时以原生微博卡片展示游客可见的公开信息流，支持下拉刷新和查看媒体；微博目前限制游客只能取首屏，更多内容与互动需登录。登录后，顶栏下拉选择「聚合 / 微博 / X」；聚合合并所有已登录账号，平台选项合并该平台全部已登录账号。按时间倒序排列，同平台同一帖子去重，各账号独立翻页；单个账号失败不阻断其他来源。
- **X（接入原型）**：读取关注信息流，用原生卡片展示正文、图片、转发、引用及广告标识；视频和互动进入对应账号的 X 网页。未接入 X 原生发布、搜索或通知。iOS 单账号登录与读取已实测；多账号真实合并、分页边界及 Android X 实机验证仍待完成，网页接口可能随平台变化而失效。
- **微博**：正文里的 @、#话题#、链接和表情；九宫格图片、长图、GIF、实况照片；转发原文；视频；广告标识（只标出来，不过滤）。
- **详情**：长微博全文、评论（按热度或时间）、楼中楼、转发列表。
- **图片和视频**：图片查看器（缩放、左右翻页、下滑关闭；实况照片点「实况」或长按播放，也可以在设置里打开自动播放），视频播放（地址过期会自动换新地址）。
- **用户主页**：资料和微博列表；从头像、昵称、@ 都能进入。
- **搜索**：未登录也能看热搜，点热搜条目可在应用内浏览微博公开网页；游客内容和翻页范围由微博限制，可能要求登录。登录后可点击顶栏右侧的搜索按钮输入关键词，并使用原生微博卡片显示搜索和 #话题# 结果（按时间从新到旧），话题还会显示导语和阅读、讨论数；结果页右上角可以切到微博网页版。
- **互动**：点赞、取消点赞，发评论、回复评论、删除自己的评论，转发（可以同时评论、选择可见范围）。只在你点击时发起，不提供任何批量或自动操作。
- **发微博**：文字加图片，可以选公开、好友圈或仅自己可见；可以删除自己的微博。
- **通知**：评论、@我的微博、@我的评论、赞；有未读时导航栏的通知图标变红，只在打开或回到应用、下拉刷新首页时检查，不在后台轮询。
- **平板和折叠屏**：正文限宽居中；宽窗口下首页卡片的图片和视频放在正文右侧，详情页的正文和评论左右并排。
- **设置**：浅色、深色或跟随系统；字体大小（滑动条，在系统字体大小的基础上调大或调小两档，带预览）；图片质量（省流量、标准、原图）；是否自动播放实况照片；图片缓存上限和清除缓存；关于与免责声明。

**不做的功能**：去广告、批量下载、会员付费内容，这三项永久不做。私信暂不支持。搜索、通知和发微博使用账号管理中选定的微博账号；信息流内微博互动使用该条目的来源账号。

## 安装

### Android

在 [Releases](https://github.com/leonfox28/tidemeld/releases) 页面下载 APK（新版本命名为 `tidemeld-vX.Y.Z.apk`，改名前的历史版本仍为 `maxbo-vX.Y.Z.apk`），所有手机都用这一个（需要 Android 7.0 及以上）。鸿蒙 HarmonyOS 5/6 可以通过卓易通安装 APK。每个 Release 都附有 `SHA256SUMS.txt`，可以用来核对下载的文件。

Android 更名保留原安装标识和签名，已有用户可覆盖安装，登录状态与设置继续保留。

从 v0.12.0 起 Android 应用用 Kotlin 重写。从更早的 Flutter 版本升级时，需要重新登录、重新设置。

### iOS

原生 iOS 版（SwiftUI，需要 iOS 26 及以上）正在测试，还没有发布安装包，可以按下面「从源码构建」自己编译。正式 Bundle ID 已改为 `io.github.leonfox28.tidemeld`，与旧正式安装是独立的应用身份。v0.2.0 到 v0.11.0 的 Releases 里附有旧的 Flutter 版未签名 IPA，那个版本不再更新。

## 从源码构建

需要 JDK 17 和 Android SDK（compileSdk 37）。Gradle 由仓库里的 wrapper 下载。

```sh
./gradlew testDebugUnitTest
./gradlew assembleRelease
```

没有 `key.properties` 时，release 包用调试密钥签名，无法覆盖安装 Releases 页面上的正式包。

iOS 版需要 Xcode 27 和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)：

```sh
cd ios
xcodegen generate
xcodebuild -project Tidemeld.xcodeproj -scheme Tidemeld -destination 'generic/platform=iOS Simulator' build
```

## 隐私

- 登录在所选平台的官方网页登录页中完成，应用的原生代码不读取你的密码或验证码。
- 登录状态只保存在你自己的设备上（Android Keystore 或 iOS 钥匙串），移除对应账号时清除。
- 维护者不运营接收用户数据的后端，没有统计、埋点或崩溃上报。所需的登录凭据、搜索词和你提交的内容会直接发送给对应平台，由平台按自身政策处理。
- 只在你操作时请求对应平台，不在后台轮询或预取，请求频率有上限。遇到验证码时，由你本人在平台页面里完成。

完整说明见[隐私政策](docs/PRIVACY.md)，使用问题见[帮助与支持](docs/SUPPORT.md)。
