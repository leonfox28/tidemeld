# maxbo 支持

maxbo 是免费、开源、非官方的微博客户端，iOS 版使用 SwiftUI，界面为简体中文。项目与微博运营方没有关联。

## 联系维护者

请在 [GitHub Issues](https://github.com/leonfox28/maxbo/issues) 提交使用问题、功能建议或隐私问题。提交需要 GitHub 账号。

请提供应用版本、系统版本、设备型号、复现步骤和错误提示。截图请先遮挡个人信息。**不要提交密码、验证码、Cookie、完整网络抓包或私人微博内容。**

## 登录与使用

未登录也可打开“搜索”页看热搜，点热搜条目或输入关键词后浏览微博公开网页。游客可见内容有限，继续翻页或互动时微博可能要求登录；登录后可使用 maxbo 的原生搜索、关注动态及互动功能。

在应用内的微博官方页面登录。验证码由你本人完成；maxbo 不会自动处理验证码。出现频率限制时，请稍后再试。接口或登录流程可能随微博调整而变化。

图片占用较大时，可到“我 → 设置”调整图片质量和缓存上限，或清除图片缓存。

## 内容与账号问题

微博内容由微博服务提供。遇到侵权、骚扰或其他不当内容，请使用微博官方的举报和黑名单功能；[微博社区管理中心](https://service.account.weibo.com/)提供相关规则和投诉信息。maxbo 维护者不能替代微博删除服务器上的内容或恢复微博账号。

如果问题涉及 maxbo 对内容的展示或应用自身行为，请通过上述 GitHub Issues 告知维护者。公开反馈时只提供必要的公开链接和问题描述，避免再次传播不当内容或私人信息。

## 隐私

详见 [maxbo 隐私政策](PRIVACY.md)。维护者不运营接收用户微博数据的后端；应用使用微博服务时的数据处理与本地存储方式在政策中分别说明。

# Support in English

maxbo is a free, open-source, unofficial Weibo client. Its app interface is in Simplified Chinese. It is not affiliated with or endorsed by Weibo.

Without signing in, open the 搜索 (Search) tab to view trending topics and browse some public results in Weibo's web page. Weibo may require sign-in for further browsing or interactions. Native search, the following feed and account actions require sign-in.

For support or privacy questions, [open a GitHub issue](https://github.com/leonfox28/maxbo/issues). Include your app version, OS version, device model and steps to reproduce. GitHub issues are public and require a GitHub account. Never post passwords, verification codes, session cookies, private posts or unredacted screenshots.

Weibo handles account access and reports about content hosted on its service. Contact [Weibo's community support](https://service.account.weibo.com/) for those matters. Contact the maxbo maintainer for problems with the app itself. See the [privacy policy](PRIVACY.md) for how local storage and requests to Weibo work.
