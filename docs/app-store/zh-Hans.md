## 名称

叠澜 Tidemeld

## 副标题

多个社交网络，一个聚合信息流

## 宣传文本

把微博与 X 的关注动态汇集到同一个原生信息流，按时间阅读，也可按平台切换。支持多个账号、图片与视频浏览、深色模式和字体调整。免费、开源。

## 描述

叠澜（Tidemeld）将多个社交网络的关注动态汇集到一个原生信息流，让你在 iPhone 和 iPad 上集中阅读。应用免费、开源，是独立的第三方客户端。

多平台聚合阅读
• 添加微博和 X 账号，支持同一平台的多个账号。
• 在“聚合 / 微博 / X”之间切换，集中查看全部已登录账号或指定平台的动态。
• 在设备上按时间合并信息流，并对同一平台的重复帖子去重。
• 卡片标明内容来源；查看正文、图片、视频、转发、引用和评论。

按平台提供互动
• 微博：搜索、热搜、用户主页与通知；点赞、评论、回复、转发和发布文字图片；删除自己的微博与评论。
• X：关注信息流、帖子与评论阅读，以及回复、点赞、转发和引用入口。X 接入仍在完善，功能范围与微博不同；暂不提供原生搜索、通知或独立新帖发布。

按自己的习惯阅读
• 浅色、深色及跟随系统主题。
• 可调整字体大小、图片质量和缓存上限。

使用前请了解
• 界面为简体中文，需要 iOS 26 或更高版本。
• 未登录时可浏览部分公开微博、热搜和公开网页结果；游客内容及翻页范围由微博限制。聚合个人关注动态需要登录对应平台账号。
• 登录在所选平台的官方网页中完成；平台可能要求短信或其他安全验证。登录凭据按账号保存在本机。
• 聚合、排序和去重在设备上完成。项目维护者不运营接收用户平台数据的后端；使用服务所需的数据直接发送给对应平台。
• 叠澜与微博、X 及其运营方没有关联，未获其背书。内容、功能及访问范围取决于平台服务、网络和账号状态；平台接口变化可能影响使用。
