# 叠澜 · Tidemeld 隐私政策

更新日期：2026 年 11 月 12 日

本政策适用于叠澜的 iOS 和 Android 客户端。叠澜（Tidemeld）是开源、免费、非官方的社交媒体聚合客户端，提供微博功能及 X 网页接入原型，与平台运营方没有关联。项目维护者不运营接收平台账号或内容的后端，不接入统计、广告或第三方崩溃上报 SDK。

## 登录与平台服务

登录时选择平台，在应用内对应平台的官方网页中完成。叠澜的原生代码不读取密码、短信验证码或登录表单；这些信息由你直接提交给所选平台及其登录验证服务。登录后，叠澜 读取网页的登录 Cookie，按平台和账号分别保存，用于以对应身份请求该平台。Cookie 相当于登录凭据，请勿向他人提供。

为了提供浏览、搜索、点赞、评论、转发和发微博功能，应用会直接向微博发送所需的登录凭据、账号标识、搜索词，以及你选择提交的文字和图片。微博及其媒体服务也会接收到建立网络连接所需的信息，例如 IP 地址和请求头。项目维护者不会接收这些请求或保存其副本。

X 接入会直接向 X 请求账号资料、关注信息流、帖子和评论。图片和视频直接访问平台的媒体服务，并在应用内查看或播放；原生媒体请求不附带账号 Cookie。回复、点赞、转发、引用及其取消操作在你主动操作后直接提交给 X，可能包含账号凭据、目标帖子标识和你输入的文字。X 的 @、话题及部分其他链接仍会打开官方网页。账号 Cookie 按来源账号用于平台请求，不发送给微博或项目维护者。X 接入仍在完善，接口变化或安全检查可能影响功能。

“维护者不收集数据”不表示平台不处理数据。微博和 X 会收到你为登录和使用服务而提供的信息，以及 IP 地址、请求头、账号或 Cookie 标识、访问记录、搜索词和互动内容等。平台的官方网页可能运行自己的脚本和使用 Cookie，并依据其政策将信息用于服务、安全、分析、个性化及广告相关处理；具体用途取决于平台功能和你的账号设置。应用内没有统计或广告 SDK，不表示这些网页也不收集数据或不进行广告相关关联。请查阅[微博个人信息保护政策](https://weibo.com/signup/v5/privacy)和 [X 隐私政策](https://x.com/en/privacy)，并在相应平台的隐私设置中管理选择。内容和账号的可用性也由对应平台决定。

未登录时，“首页”通过微博的游客接口获取部分公开微博，并用原生列表显示；你也可以在“搜索”页查看热搜及部分公开网页。首次获取游客信息流时，应用可能临时运行微博官方网页的游客流程以取得游客 Cookie，随后停止该网页；这些 Cookie 不会被当作账号登录状态。iOS 使用临时网页存储，Android 使用应用内网页的 Cookie 存储，并验证服务端返回未登录状态后才读取游客信息流。游客请求、搜索词、媒体和网页访问直接发送给微博；微博可能记录网络信息或要求登录。游客访问不代表匿名于微博，也不保证可以查看全部内容。

## 设备上的数据

- 登录状态：iOS 存储于本机钥匙串，设置为不迁移到其他设备；Android 使用 Android Keystore 保护的密钥加密保存。不同平台、同平台不同账号的凭据分别保存。应用内网页还会保留对应平台的 Cookie 和网站数据；打开账号对应的网页时切换该平台浏览器会话，其他账号的原生请求仍使用各自凭据。
- 设置：主题、字体、图片质量、已同意的使用条款版本及内容过滤关键词保存在本机。关键词匹配在设备上完成，不上传规则。原生帖子、引用与评论命中规则时折叠；这些规则不改变平台账号设置或网页内容。平台标记为敏感的 X 媒体默认不加载，可逐条选择显示。
- 举报与拉黑：举报入口使用对应来源账号打开微博或 X 的官方页面，你选择原因并提交后由该平台处理。拉黑及取消操作直接发送到对应平台；平台确认后，本机按来源账号保存被拉黑用户的 ID，用于立即隐藏其原生内容。不同来源账号互相独立；取消拉黑并确认后移除对应的本地记录。
- 图片缓存：已查看的图片保存在本机缓存中，受你设置的容量上限约束，可在“设置”中清除。
- 草稿：未发送的文字暂存在当前运行的应用中；所选图片会暂存在应用目录中。移除图片、完成发送、退出登录或更换账号时清理相应草稿；下次启动也会清理遗留的临时草稿图片。

叠澜不将登录凭据或内容上传到项目维护者的服务器；原生代码不读取广告标识符、不建立用于跨应用跟踪的用户档案。平台及其网页的数据处理见上文，不能由此推断平台不会关联你的访问。聚合、排序和去重只在设备上完成。应用不会在后台定时轮询平台；请求由打开应用、浏览、刷新或其他交互触发，并限制频率。

## 照片与外部页面

选择发博或评论图片时，叠澜 使用系统照片选择器，只读取你选中的图片，点击发送后才上传到微博。上传的图片文件可能带有原始元数据；如不希望分享拍摄地点等信息，请先处理图片。应用不申请通讯录、定位或麦克风权限。

你打开外部链接时，对应网站或浏览器会按自身政策处理数据。项目主页、隐私政策在线版本和问题反馈位于 GitHub；访问或提交反馈适用[GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。

## 删除与撤回

- 在“账号管理”中移除账号，会清除该账号保存在账号列表中的登录凭据；若应用内浏览器正在使用该账号，也清除该平台的浏览器 Cookie。其他账号保持登录。已打开页面、未发送草稿和网站缓存可能暂存在本次运行中；关闭应用可结束本次会话。
- 在“设置”中清除图片缓存，可删除已缓存的图片；移除账号不会自动清除图片缓存和个人设置。
- 卸载应用会移除应用目录中的本地数据。iOS 钥匙串项目可能在卸载后保留，叠澜 在重新安装后的首次启动时清理残留登录状态；建议卸载前先移除已登录账号。
- 移除本地账号不会注销微博或 X 账号，也不会删除已发布内容。你可以在应用内删除自己的微博或评论；注销账号、X 内容处理及其他数据请求请使用对应平台官方提供的入口。
