# 叠澜 Tidemeld 使用条款

版本：2026-11-12

使用叠澜前，请阅读并同意以下条款。叠澜是独立、免费的第三方社交阅读客户端，不隶属于微博或 X。添加平台账号仅用于访问该平台的内容和功能，不会创建叠澜账号。

## 内容与行为

叠澜不容忍不当内容或滥用行为。不得使用叠澜发布、传播或实施骚扰、欺凌、仇恨、威胁、色情、儿童性剥削、诈骗、侵犯隐私或知识产权，以及其他违法或违反对应平台规则的内容和行为。

你应对自己发布和传播的内容负责，尊重他人，并遵守微博或 X 的服务条款和社区规则。不得利用叠澜绕过平台的访问限制、内容限制或安全验证。

## 举报、拉黑与过滤

遇到不当内容，请从帖子、评论或用户主页的举报入口进入对应平台的官方流程，选择原因并完成提交。举报由对应平台受理，处理结果以平台通知为准。打开举报页面不表示举报已提交。

你可以使用对应平台的拉黑功能限制与该用户的互动。平台确认拉黑成功后，叠澜会立即隐藏当前来源账号下该用户的原生内容；平台其他账号的关系独立管理。取消拉黑可在该用户主页操作。

设置中的内容过滤支持本机关键词规则。被 X 标记为敏感的媒体默认隐藏。过滤规则不改变平台网页的内容或平台设置；未被标记的内容也可能需要你举报或拉黑。

## 账号与隐私

你直接在对应平台的官方网页中登录。登录状态保存在本机，移除账号仅清除叠澜中的本机登录状态，不会删除平台账号。具体数据处理方式见应用内的《隐私政策》。

## 联系与更新

应用使用问题可通过“设置 → 关于 → 问题反馈”或 https://github.com/leonfox28/tidemeld/issues 联系维护者。请勿在公开反馈中包含密码、Cookie、验证码或他人的私密信息。

平台决定其内容和账号的处理结果。叠澜的功能可能随平台变化而调整。条款发生实质变化时，应用会再次请你确认。
